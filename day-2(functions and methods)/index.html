Functions and Methods

Function

A block of code that performs a apecific tasks,can be invoked whenever needed.

Function Parameter

It is like a local variables of functions have block scope and are limited for block only.

Arrow Functions

Compact way of writing a function.

Callback Function

It is a function that we give to another function as an argument.

Higher-order function

It is a function that receives or returns a function.

Immediately Invoked Functions Expression(IIFE)

It is a JavaScript function that is created and executed immediately,without needed to be called separately later.

Some More Array Methods

map()

Create a new array with the result of some operation.The value ist callback returns are used to form new array.

filter()

It is used to filter out the element based on the condition.

reduce()

It performs some operation and reduce the array to a single value and return that value.
