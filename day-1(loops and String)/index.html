Loops and Strings

Loops in JS

Loops are used to execute a piece of code again and again.

  • for loop
  • while loop
  • do while

There are other loop to which are as follow:

  1. Infinite loop - A loop that never ends.
  2. for-of loop - used for Strings and Arrays.
  3. for-in loop - used for Objects.

Template Literals in JS

A way to have embedded expression in strings

Strings in JS

Strings is the sequence of characters used to represent text.

Strings Methods in JS

  • .toUpperCase()-change to UpperCase.
  • .toLowerCase()-change to LowerCase.
  • .trim()- remove the whitespace.
  • .slice(start,end)-return the specific part of the string.
  • .concat()-used to join the two Strings.
  • .replace()-used to replace the first occurence of the giving String
  • .charAt(idx)-used to get the character of particular index.
